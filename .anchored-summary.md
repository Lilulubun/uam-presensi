## Known gotchas
- **node_modules drift**: this worktree lives inside the main checkout. After `npm test` you may see modifications to `node_modules/tsx/`, `node_modules/.package-lock.json`, etc. These are npm housekeeping side effects, NOT your changes. Stage only `src/` (or use `git add <files>`) to keep commits clean. Never commit node_modules.
- **Don't remove the top-level `getTpaById` / `getTpaByStaticQR` exports from `tpaStore.ts`**. Components import them as top-level functions, not via the hook.
- **RLS + pgcrypto required 2 fix migrations** (`0004`, `0005`). When re-applying migrations on a fresh DB, apply 0001–0003 first, then 0004, then 0005.
