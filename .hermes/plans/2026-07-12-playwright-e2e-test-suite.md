# Playwright E2E Test Suite Implementation Plan

> **For Hermes:** Use the superpowers:subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Build a robust, multi-device simulated E2E test suite for the uam-presensi system, covering authentication, session creation, real-time joiner check-in, and finalization.

**Architecture:** Use Playwright's Multi-Context browser feature to simulate two independent users (Host and Joiner) interacting simultaneously. Geolocation mock controls will verify GPS-radius rules.

**Tech Stack:** Playwright Test, Chromium, TypeScript, React 18, Vite.

---

## Global Constraints

- Playwright tests live in the `e2e/` folder.
- All test runs use the local development server running on `http://localhost:5173`.
- Mocking Geolocation is required for host & joiner pages inside `playwright.config.ts` or during context creation.
- Supabase calls will hit the real database via the configured `.env` variables.

### Task 1: Setup Multi-Context Authentication Helper

**Objective:** Write a clean authentication helper to login users in Playwright contexts without repeating input selectors.

**Files:**
- Create: `e2e/helpers/auth.ts`
- Test: `e2e/helpers/auth.ts`

**Interfaces:**
- Consumes: Page and credentials object.
- Produces: `loginAs(page: Page, role: 'pengajar' | 'pengurus', nimOrEmail: string, password: string)`

- [ ] **Step 1: Write helper function code**
```typescript
import { Page, expect } from '@playwright/test';

export async function loginAs(page: Page, nimOrEmail: string, password: string) {
  await page.goto('/login');
  await expect(page.getByText('Memuat...')).toBeHidden({ timeout: 15000 });
  await page.getByLabel('NIM').fill(nimOrEmail);
  await page.getByLabel('Password').fill(password);
  await page.getByRole('button', { name: 'Masuk' }).click();
}
```

### Task 2: Implement Host Session Creation (Valid vs Invalid Location)

**Objective:** Verify that a teacher (Host) can only open an attendance session when their GPS is within the registered TPA's radius.

**Files:**
- Create: `e2e/host-session.spec.ts`

**Step 1: Write E2E test for geolocation validation**
```typescript
import { test, expect } from '@playwright/test';
import { loginAs } from './helpers/auth';

test.describe('Host Session Creation', () => {

  test('should deny session opening when outside TPA radius', async ({ browser }) => {
    // Set GPS coordinates far away (e.g., Jakarta center)
    const context = await browser.newContext({
      permissions: ['geolocation'],
      geolocation: { latitude: -6.2088, longitude: 106.8456 }
    });
    const page = await context.newPage();
    await loginAs(page, '20521001', '23523198uam');
    
    await page.goto('/pengajar/scan');
    // Expect error toast indicating GPS is outside radius
    await expect(page.getByText(/Anda berada di luar radius/i)).toBeVisible({ timeout: 10000 });
    await context.close();
  });

  test('should create session successfully when inside TPA radius', async ({ browser }) => {
    // Set GPS coordinates exactly at TPA Al-Fath
    const context = await browser.newContext({
      permissions: ['geolocation'],
      geolocation: { latitude: -7.6864, longitude: 110.4183 }
    });
    const page = await context.newPage();
    await loginAs(page, '20521001', '23523198uam');

    await page.goto('/pengajar/scan');
    // Verify redirection to active session screen
    await expect(page).toHaveURL(/.*\/pengajar\/session\/.*/, { timeout: 15000 });
    await context.close();
  });

});
```

### Task 3: Implement Real-Time Joiner Check-In Flow (Multi-Device Flow)

**Objective:** Test the core flow where a joiner scans the QR generated by the host and gets checked in.

**Files:**
- Create: `e2e/joiner-checkin.spec.ts`

**Step 1: Write E2E test with multi-device simulation**
```typescript
import { test, expect } from '@playwright/test';
import { loginAs } from './helpers/auth';

test('should allow joiner to check in and show up on host list', async ({ browser }) => {
  // 1. Host logs in and opens session
  const hostContext = await browser.newContext({
    permissions: ['geolocation'],
    geolocation: { latitude: -7.6864, longitude: 110.4183 }
  });
  const hostPage = await hostContext.newPage();
  await loginAs(hostPage, '20521001', '23523198uam');
  await hostPage.goto('/pengajar/scan');
  await expect(hostPage).toHaveURL(/.*\/pengajar\/session\/.*/, { timeout: 15000 });

  // Extract the dynamic token from the QR element
  const qrElement = hostPage.locator('[data-qr-token]');
  await expect(qrElement).toBeVisible();
  const token = await qrElement.getAttribute('data-qr-token');
  expect(token).not.toBeNull();

  // 2. Joiner logs in on another browser instance
  const joinerContext = await browser.newContext({
    permissions: ['geolocation'],
    geolocation: { latitude: -7.6865, longitude: 110.4184 }
  });
  const joinerPage = await joinerContext.newPage();
  await loginAs(joinerPage, '20521002', '23523198uam');

  // Joiner accesses check-in page with the dynamic token
  await joinerPage.goto(`/pengajar/konfirmasi?token=${token}`);
  await joinerPage.getByRole('button', { name: 'Konfirmasi Hadir' }).click();

  // Verify joiner gets successfully checked in
  await expect(joinerPage.getByText(/Presensi berhasil dicatat/i)).toBeVisible();

  // Verify host's dashboard updates real-time showing the joiner's name
  await expect(hostPage.getByText('Siti Rahayu')).toBeVisible({ timeout: 10000 });

  await hostContext.close();
  await joinerContext.close();
});
```

### Task 4: Implement Session Finalization and Close Out

**Objective:** Test that closing the session as a Host requires entering materials notes and successfully wraps up all joiners' attendance status.

**Files:**
- Create: `e2e/session-finalize.spec.ts`

**Step 1: Write E2E test for closing session**
```typescript
import { test, expect } from '@playwright/test';
import { loginAs } from './helpers/auth';

test('should require notes and successfully close the session', async ({ browser }) => {
  const hostContext = await browser.newContext({
    permissions: ['geolocation'],
    geolocation: { latitude: -7.6864, longitude: 110.4183 }
  });
  const hostPage = await hostContext.newPage();
  await loginAs(hostPage, '20521001', '23523198uam');
  await hostPage.goto('/pengajar/scan');
  await expect(hostPage).toHaveURL(/.*\/pengajar\/session\/.*/, { timeout: 15000 });

  // Click close session button
  await hostPage.getByRole('button', { name: /Tutup Sesi/i }).click();

  // Dialog opens. Fill the notes input.
  const notesField = hostPage.getByPlaceholder(/Materi yang diberikan hari ini/i);
  await expect(notesField).toBeVisible();
  await notesField.fill('Belajar Ilmu Tajwid Keras');

  // Submit dialog
  await hostPage.getByRole('button', { name: /^Tutup Sesi$/ }).click();

  // Expect redirect back to dashboard
  await expect(hostPage).toHaveURL(/.*\/pengajar\/dashboard/i, { timeout: 15000 });

  await hostContext.close();
});
```
